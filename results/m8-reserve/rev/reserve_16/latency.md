## Method

- file: `data/12302019.NASDAQ_ITCH50.itch50.sample`; every message timed, nothing excluded (cold start included)
- timed span: one `dispatch()` = decode + order store + book update (framing loop excluded)
- clock: TSC via `lfence; rdtsc` ... `rdtscp; lfence`; invariant TSC: yes
- calibration: 1.9962 ticks/ns (3 x 200 ms vs steady_clock: 1.9962, 1.9962, 1.9962)
- timer overhead (empty begin/end pair, 1M samples): p50 41.6 ns, p99 41.6 ns (bucket bounds); exact median 80 ticks = 40.1 ns; included in every raw number
- clock resolution: smallest visible TSC step 20 ticks = 10.0 ns; differences below that are not resolvable
- thread: pinned to logical CPU 2, THREAD_PRIORITY_HIGHEST
- runs: 3, each with a fresh handler; state hash checked after each run
- histogram: log-linear, 16 sub-buckets per power of two; values are bucket upper bounds (<= 6.25% high)
- build: g++ 16.2.0, optimised, NDEBUG
